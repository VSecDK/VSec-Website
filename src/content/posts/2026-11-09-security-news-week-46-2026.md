## Top 5 Noteworthy Vulnerabilities This Week

### CVE-2026-105134 | Ahsay AhsayCBS | OS Command Injection

**CVSS: 10 (CRITICAL)** | **EPSS: 0.0%** | **Sightings last 7 days: 6**
A flaw has been found in Ahsay AhsayCBS up to 9.15.2.69/10.3.4.44, which affects the Replication Receiver component. Executing a manipulation of the argument random can lead to OS command injection. It is possible to launch the attack remotely. The exploit has been published and may be used. Upgrading to version 9.15.2.70 can fix the issue.

### CVE-2026-116779 | signalwire freeswitch | Command Injection

**CVSS: 9.8 (CRITICAL)** | **EPSS: 0.0%** | **Sightings last 7 days: 7**
FreeSWITCH is a Software Defined Telecom Stack enabling the digital transformation from proprietary telecom switches to a software implementation that runs on any commodity hardware. Prior to 1.11.3, sofia_presence_handle_sip_i_message() split the To user of an inbound SIP MESSAGE on a plus sign and treated the left side as a chat protocol selector. Selecting the api chat proto reached switch_api_. This vulnerability can be exploited remotely.

### CVE-2026-102895 | gpustack gpustack | Privilege Escalation

**CVSS: 9.8 (CRITICAL)** | **EPSS: 0.0%** | **Sightings last 7 days: 10**
GPUStack is an open-source GPU cluster manager for AI model serving and GPU instance provisioning. Prior to 2.2.0, get_current_user in gpustack/api/auth.py treated a loopback request source as the built-in administrator when force_auth_localhost was false, which was the default. A remote request could appear to originate from 127.0.0.1 because client_ip_getter accepted a same-host reverse proxy. This vulnerability can be exploited remotely.
